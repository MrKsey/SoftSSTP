# SoftSSTP

SSTP VPN client for Android, built with Flutter and Material Design 3. Works with
any server that speaks Microsoft SSTP (MS-SSTP), such as SoftEther VPN Server and
VPN Azure.

- Full description, screenshots and troubleshooting: [project README](../README.md)
- Downloads: [Releases](https://github.com/MrKsey/SoftSSTP/releases)
