# SoftSSTP

[English](README.md) · **Русский**

Современный открытый **SSTP VPN-клиент для Android**, написанный на Flutter с
интерфейсом в стиле Material Design 3. Работает с любым сервером, поддерживающим
протокол Microsoft **SSTP (MS-SSTP)** — чаще всего это
[SoftEther VPN Server](https://www.softether.org/) и
[VPN Azure Cloud](https://www.vpnazure.net/).

## На основе

SoftSSTP — форк проекта
**[CluvexStudio/ZedPass](https://github.com/CluvexStudio/ZedPass)**, который, в
свою очередь, построен на оригинальной реализации протокола SSTP.

| Слой | Проект | Роль |
|------|--------|------|
| Протокол SSTP / PPP / TLS | [kittoku/Open-SSTP-Client](https://github.com/kittoku/Open-SSTP-Client) (MIT) | Исходный Android-клиент SSTP; на его движке основан протокол здесь. |
| Плагин Flutter | [NavidShokoufeh/sstp_flutter](https://github.com/NavidShokoufeh/sstp_flutter) | Flutter-обёртка над этим движком. |
| Базовое приложение | [CluvexStudio/ZedPass](https://github.com/CluvexStudio/ZedPass) | Проект, на котором основан этот форк. |
| Этот проект | **SoftSSTP** (этот репозиторий) | Переработанное приложение **и** пропатченный `sstp_flutter` с исправлениями и новыми функциями. |

## Возможности

- **Интерфейс Material Design 3** с темой Material You.
- **Дневной / ночной / авто режим** — нажмите на иконку в левом верхнем углу,
  чтобы переключаться между *авто* (как в системе), *днём* и *ночью*.
- **Несколько профилей VPN** — можно держать рядом несколько серверов. В каждом
  профиле хранятся все его настройки (сервер, DNS, прокси, PPP, маршрутизация,
  раздельное туннелирование, автопереподключение, дополнительные параметры), а
  также имя и цвет иконки. Активный профиль выбирается на главном экране; новый
  профиль создаётся только после нажатия **Save**.
- **Публичные профили из VPN Gate** — список публичных MS-SSTP-серверов (флаг
  страны, качество линии и измеренный с устройства пинг), любой из которых
  добавляется как готовый профиль (логин `vpn` / пароль `vpn`) одним нажатием.
- **Подключение / отключение** с контролем состояния на главном экране и в
  уведомлении.
- **Текущая скорость** (в битах) и **общий объём трафика** (в байтах).
- **Публичный IP и геолокация** до и после подключения, а также **внутренний IP**,
  выданный сервером.
- **Раздельное туннелирование** — только выбранные приложения, с поиском по
  списку. Выбор сохраняется, даже если правило выключить.
- **Автопереподключение** с настройкой числа попыток и интервала.
- **Автоматический перезахват VPN-слота** — если другое VPN (например AdGuard)
  отбирает слот, SoftSSTP возвращает его и переподключается сам.
- **Автовосстановление при смене сети** — переключение Wi-Fi ↔ мобильные данные
  автоматически пересобирает туннель.
- **Полный контроль DNS / прокси / SSL / PPP:** свой DNS, HTTP-прокси, свой SNI,
  версия SSL, проверка имени хоста и сертификата, MTU/MRU, протокол
  аутентификации, IPv4/IPv6, статический IP и маршрутизация.
- **Счётчики трафика**, переживающие выключение экрана и пересоздание приложения.

### Исправления по сравнению с оригинальным движком

- **Исправление TLS-рукопожатия** — в оригинале использовался
  `SSLContext.getInstance("TLSv1.3")`, который выбрасывает исключение на Android.
  В SoftSSTP используется общий контекст `"TLS"`, добавлены свой SNI и защита
  сокета.
- **Учёт трафика без потери скорости** — в оригинале на каждый пакет отправлялся
  вызов MethodChannel в главном потоке, что ограничивало скорость. В SoftSSTP
  используются lock-free счётчики с отчётом раз в секунду.

## Требования

- Android 8.0 (API 26) или новее
- Доступный SSTP-сервер с включённым DHCP
- Поддерживаются только **PAP** и **MS-CHAPv2** (без EAP)

## Установка

1. Откройте страницу [**Releases**](https://github.com/MrKsey/SoftSSTP/releases).
2. Скачайте APK под своё устройство:
   - `SoftSSTP-<версия>-arm64-v8a.apk` — современные 64-битные устройства
     (**рекомендуется**)
   - `SoftSSTP-<версия>-armeabi-v7a.apk` — старые 32-битные устройства
3. Установите APK (при необходимости разрешите установку из браузера/файлового
   менеджера).
4. Откройте SoftSSTP, зайдите в **Настройки**, введите данные сервера и
   подключитесь.

> Все релизы подписаны одним и тем же сертификатом, поэтому обновления
> устанавливаются поверх предыдущей версии без удаления.

## Использование

1. Нажмите на шестерёнку, чтобы открыть **Настройки**. В блоке **Profiles** можно
   добавлять, редактировать, делать активными и удалять профили; там же находятся
   **Diagnostics** и **About**.
2. Откройте профиль и укажите **Хост**, **Порт** (по умолчанию `443`), **Логин**
   и **Пароль**. При желании задайте имя и цвет иконки, затем нажмите **Save**.
3. Дополнительно настройте DNS, прокси, SSL, PPP, маршрутизацию и раздельное
   туннелирование.
4. Чтобы добавить готовый публичный сервер, нажмите **Add public profile** и
   выберите сервер из списка VPN Gate.
5. На главном экране нажмите на карточку сервера, чтобы сменить активный профиль,
   затем нажмите кнопку подключения. Чтобы отключиться, нажмите кнопку ещё раз
   или коснитесь уведомления.

## Решение проблем

### Работает другое VPN (AdGuard)

Android разрешает активным только **один VPN одновременно**. SoftSSTP захватывает
VPN-слот прямо перед подключением, поэтому обычно **автоматически вытесняет
другое VPN**. Если то VPN снова перехватывает слот (у него есть сторож) или вы
видите, что туннель переподключается сам, — это ожидаемо: SoftSSTP **дожидается,
пока другое VPN запустится, затем возвращает слот** и переподключается, а
уведомление показывает происходящее.

Если слот так и не удаётся удержать, у другого приложения, скорее всего, включён
**постоянный VPN (Always-on VPN)**, который система не разрешает вытеснять:

- отключите **постоянный VPN** у другого приложения
  (*Настройки → Сеть и интернет → VPN → шестерёнка*);
- либо добавьте **SoftSSTP** в список исключений (в AdGuard:
  *Настройки → Управление приложениями → SoftSSTP* → **Обход**);
- либо переключите AdGuard в **режим прокси** вместо режима VPN.

### Смена сети (Wi-Fi ↔ мобильные данные)

Сокет SSTP привязан к нижележащей сети, поэтому её смена разрывает туннель.
SoftSSTP следит за сетью и **сам пересобирает туннель** в новой — вручную
подключаться не нужно. И это, и перезахват слота ограничены по числу попыток,
поэтому «мигающая» сеть или постоянный перехват не вызовут бесконечного цикла.

## Сборка из исходников

```bash
# Требуется: Flutter (stable), JDK 17, Android SDK

git clone https://github.com/MrKsey/SoftSSTP.git
cd SoftSSTP/SoftSSTP

flutter pub get
dart run flutter_launcher_icons

# Универсальный APK
flutter build apk --release

# APK по архитектурам (arm64 + arm)
flutter build apk --release --split-per-abi \
  --target-platform android-arm64,android-arm
```

APK появятся в `build/app/outputs/apk/release/`.

Пуш в `main` (или тег `v*`) запускает CI, который собирает обе архитектуры и
публикует GitHub Release. Версия автоматически инкрементируется от наибольшего
существующего тега (`1.0.0`, `1.0.1`, `1.0.2`, …) либо берётся из
отправленного тега; сборки подписываются стабильным ключом из секретов
репозитория.
